How it works

  1. Same code on both screens. Type the code from one device into the other. Its first 4 digits only pick a meeting point; the last 5 are a secret that never leaves the two devices.
  2. Sealed handshake through the pipe. The devices prove they share the secret (CPace) and swap connection details sealed with the resulting key. The pipe server relays four small sealed notes and can neither read nor change them, and nobody can test guesses at the secret offline.
  3. Direct from then on. The browsers connect to each other. Messages and files go device to device, encrypted; they never pass through the pipe server.
